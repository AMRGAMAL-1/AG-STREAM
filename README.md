## لماذا هذا المستودع؟

- **تغطية واسعة**: أكثر من 40 مزود عربي للأفلام والمسلسلات والأنمي والرياضة.
- **تحديث تلقائي**: البناء يتم تلقائياً مع كل تحديث، بدون أي تدخل منك.
- **خفيف وسريع**: إضافات مختارة بعناية لتجربة مشاهدة سلسة على الموبايل والشاشات.
- **حصرياً**: مزود **CimaMix** الجديد — دعم موقع `cimamix.net` للأفلام والمسلسلات المترجمة بجودة عالية.

## طريقة التركيب

1. افتح تطبيق **Cloudstream**.
2. ادخل على **الإعدادات ⚙️ ← الإضافات ← إضافة مستودع**.
3. الصق الرابط التالي:

```text
https://raw.githubusercontent.com/AMRGAMAL-1/AG-STREAM/refs/heads/main/repo.json
```

4. افتح المستودع من قائمة الإضافات وحمّل المزودات اللي تعجبك.
5. ارجع للرئيسية واختار المزود من زر المزودات أسفل الشاشة وابدأ المشاهدة.

> نفس الرابط يشمل أيضاً المزودات الأجنبية (أفلام ومسلسلات بالإنجليزية) — تظهر مع باقي الإضافات داخل نفس المستودع.

### رموز مختصرة (للشاشات والريموت)

بدل كتابة الرابط كامل، اكتب واحد من الرموز دي في خانة إضافة المستودع:

| الرمز | الوصف |
|-------|--------|
| `Amr1` | الرمز الأساسي |
| `3amr` | رمز بديل |

> ملحوظة: الرموز تعمل عبر خدمة `cutt.ly` — لو رمز ما اشتغلش جرّب الرابط الكامل فوق.

## لمستخدمي التلفاز (Android TV)

كتابة الروابط بالريموت متعبة، فالحل الأسهل:

1. افتح **الإعدادات ← الإضافات ← إضافة مستودع**.
2. اكتب الرمز المختصر فقط (`Amr1`) بدل الرابط الطويل.
3. لو ظهرت رسالة فشل في التحميل: غيّر الـ **DNS** من إعدادات Cloudstream ثم حاول مجدداً.

## حل المشاكل

| المشكلة | الحل |
|---------|------|
| المستودع لا يُفتح | جرّب الرابط الكامل بدل الرمز، أو فعّل VPN |
| لا توجد سيرفرات لفيلم معين | جرّب مزوداً آخر، أو أعد المحاولة لاحقاً |
| التطبيق لا يحدّث الإضافات | احذف المستودع وأعده، ثم حدّث الإضافات |
| مشاكل الشبكة على الشاشة | غيّر DNS من الإعدادات (مثلاً `8.8.8.8`) |

## المساهمة

المساهمات مرحب بها:
- اقتراح مزود جديد: افتح **Issue** باسم الموقع ورابطه.
- تحسين مزود موجود: اعمل **Fork** ثم **Pull Request**.
- الإبلاغ عن عطل: اذكر اسم المزود + اسم الفيلم/المسلسل + لقطة شاشة إن أمكن.

### قاعدة إلزامية لأي مزود (جديد أو معدل)

**ممنوع وضع رابط ميديا خام (`.m3u8` / `.mp4`) في `SearchResponse.url` أو `dataUrl` أو `Episode.data`.**
عميل الديسكتوب يخطف الروابط الخام إلى محلل yt-dlp فتظهر كمسلسل وهمي
بعنوان `playlist <تاريخ>` وبدون حلقات. القاعدة:
- البطاقات والحلقات تحمل روابط **صفحات الموقع** فقط.
- رابط الميديا الحقيقي يُكشف داخل `load()` / `loadLinks()` فقط.
- روابط `ExtractorLink` (المشغل) مستثناة — المشغل يتعامل مع الميديا مباشرة.

## تنبيه حقوق (DMCA)

هذه الإضافات تعمل مثل متصفح الويب: تجلب روابط المشاهدة من مواقع طرف ثالث، **ولا تستضيف أي محتوى** على هذا المستودع أو داخل تطبيق Cloudstream. الاستخدام مسؤولية المستخدم وفق قوانين بلده. لأي بلاغ حقوق، تواصل مع المواقع المستضيفة للملفات وليس مع مطوري المستودع.
